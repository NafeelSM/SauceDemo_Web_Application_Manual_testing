SauceDemo Web Application - Manual Testing Project
📌 Project Overview

This repository contains the complete Manual Testing documentation and deliverables for the SauceDemo Web Application. The project was created to demonstrate the end-to-end Software Testing Life Cycle (STLC), from test planning and test case design to test execution, defect reporting, and final test summary.

🎯 Testing Objectives <br>

The main objectives of this project are: <br>

Verify the functionality of the SauceDemo web application. <br>
Identify and document functional defects. <br>
Ensure that the application meets the defined requirements. <br>
Execute designed test cases and record test results. <br>
Provide a comprehensive test summary based on the testing activities. <br>


📂 Project Contents <br>
Test Plan – Defines the testing scope, objectives, approach, resources, schedule, and deliverables. <br>
Test Scenarios – Contains high-level scenarios covering the application's major functionalities. <br>
Test Cases – Detailed test cases with test steps, expected results, actual results, and execution status. <br>
Bug Reports – Documents defects identified during test execution, including severity, priority, steps to reproduce, and expected/actual results. <br>
Test Execution – Contains the execution results and status of the designed test cases. <br>
Test Summary Report – Provides an overall summary of testing activities, results, defects, and final testing observations.
